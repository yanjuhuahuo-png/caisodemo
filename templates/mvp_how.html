交易语义（Return = DA − RTPD，$/MWh）

SELL_DA
预期 Return > 0 → 卖 DA、买 RT 平仓。
PnL = DA − RTPD = actual_return
BUY_DA
预期 Return < 0 → 买 DA、卖 RT 平仓。
PnL = RTPD − DA = −actual_return
NO_TRADE
信号弱 / 风控拒绝 / 数据缺失 → 不建仓。
PnL = 0（但可能承担机会成本或避免亏损）
1 MWh/仓。实际价格（actual_*）在 LOCK 之前绝不显示，只在 Post-trade 揭晓用于复盘，绝不回灌决策。

为什么这是"Agent"而不是一张报表

  • Agent Evidence 采集：决策时点自动拉取真实外部证据（GFS 历史预报），并经 Evidence Time Gate 程序裁决——晚于 10:00 PT cutoff 的证据被隔离，只进复盘，绝不进入决策。
  • Case Retrieval（as-of）：只检索 case_available_at ≤ 决策时点的已结算案例，防 Case 穿越。
  • 白盒推导链：Model Opinion → Evidence → Risk Gate → Rule Engine → Final，每一步有 reason_code 与业务翻译。
  • Ask Trading Agent：自然语言追问决策，LLM 通过 6 个结构化 Tool（get_decision / get_feature_explanation / get_evidence / get_similar_cases / get_data_provenance / get_post_trade_review）获取事实并展示 Agent Trace。
  • 不造假：决策路径无 MOCK；无真实证据时诚实显示 "NO ELIGIBLE EXTERNAL EVIDENCE"，宁可知晓未知，不可编造方向。

Agent 做什么 / 不做什么

✓ Agent 做什么
  • 理解交易员的问题
  • 调用决策工具（查询建议 / 特征 / 证据 / 案例 / 数据血缘 / 复盘）
  • 解释系统为什么这么判断
  • 事后帮助复盘
✕ Agent 不做什么
  • 不自行修改交易方向（BUY / SELL / NO_TRADE）
  • 不绕过 Risk Gate
  • 不编造市场数据
  • 不使用截止后的未来信息
  • 不自动下单
关键

LLM 不直接决定 BUY / SELL。 交易方向一律由白盒 DecisionService + 规则引擎 + 风控程序决定；LLM 只解释，且不能修改/覆盖工具返回的数字与最终建议（程序化完整性守卫拦截）。

诚实边界

重要

Signal / Strategy MVP, Not Full CAISO Settlement Simulator. MODEL SIGNAL IS EXPERIMENTAL / CURRENT ALPHA = WEAK / MVP ≠ 已验证盈利系统。 无 BUY_DA 放行真实例（test 窗口 BUY 被 Risk Gate 系统性拒绝）——系统保守是设计而非遗漏。 PnL 按 1 MWh/仓 简化；结算仅覆盖 DAM/RTPD 价差，不含 FMM/阻塞/费用等完整结算。
