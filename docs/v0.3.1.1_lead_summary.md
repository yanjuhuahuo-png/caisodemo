## 4. Lead 回答 6 个问题

**Q1：一个全新 GitHub clone，无完整研究数据，能否直接运行 Golden Case Web Demo？**
**YES。** `demo_artifacts/` 最小真实切片 + `prepare_mvp` 自动 DEMO 模式，clean clone 模拟验证通过（5 Golden Case 与 FULL 一致）。

**Q2：Demo Mode 是否使用 MOCK 数据参与交易推荐？**
**NO。** DEMO 是真实历史切片（`contains_mock=false`，manifest+哈希验证），可真实推荐；MOCK 恒隔离（H3 验证）。

**Q3：Web 页面展示的 Evidence available_at 是否和 Time Gate 实际使用时间完全一致？**
**YES。** `_ev_row` 修复 + `feature_available_at_display` 单一事实来源；`available_at_source` 诚实标注（H5/H6/H7 验证）。

**Q4：Audit Panel 的 PASS 是否全部来自真实运行检查，而不是硬编码？**
**YES。** 5 项 Runtime Audit 真实运行，OVERALL 由真实 status 推导（H8 源码分支验证）；FAIL 可真实触发（H9）。

**Q5：Web / CLI / LLM Tools 是否使用同一个 DecisionSnapshot？**
**YES。** Web 与 Tool 复用同一 `decision_id`，CLI 决策链 final 与 Web 一致（H13）。

**Q6：本轮是否修改了任何交易 Alpha / 阈值 / PnL 以改善 Demo 表现？**
**NO。** 交易核心冻结；全部改动为工程/审计/展示加固，未改模型/规则/阈值/PnL。

## 5. 诚实边界

- `check_demo_consistency`（FULL vs DEMO）在当前完整数据机上实跑 5/5；真正 clean clone 上该测试按设计 SKIP（需完整数据机复核）。
- `prepare_mvp.py` 在 GBK 管道下打印 ⚠ emoji 可能 UnicodeEncodeError（用 `-X utf8` 或 `python -X utf8 prepare_mvp.py` 正常）；不影响模式探测。
- 展示类 z-score 用 90 天前置窗口（FULL 用全历史）——属展示项，不影响决策字段。

## 6. 结论

**V0.3.1 MVP 达到 Demo Freeze 条件**：clean clone 可稳定启动演示、页面与真实运行一致、数据可追溯、时间字段前后一致、Audit 全真实、Outcome 由 APPLICATION-LAYER OUTCOME ACCESS CONTROL 隔离（Lock 前实际结果绝不暴露）、无 MOCK 冒充、未改交易结果。后续（EV/Tail-aware Model、真实 Evidence Alpha、更多 CAISO 数据、Production Shadow Test）均不属于本轮。
