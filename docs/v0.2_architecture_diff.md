## 0. 摘要（TL;DR）

V0.1 → V0.2 的架构变化是**定位与流程的重新设计**，不是数据/模型精度提升：

- **模型定位**从"三层模型委员会投票"改为"**单一 Production Predictive Model + Rule=基准 + Interpretable=开发工具**"——线上只跑一个模型，它只输出预测量（expected_return / prob / confidence / uncertainty），**不输出 BUY/SELL**。
- **决策流程**从"模型 → 三态决策"扩展为 **8 步受控流水线**（预测 → 证据 → 时间门 → 案例 → 风控 → 规则引擎 → 人工确认 → 复盘），并在证据层新增 **Evidence Time Gate** 作为防穿越硬约束。
- **cutoff 修正**：13:00 → **10:00 PT**（DAM Market Close，官方 BPM 口径；13:00 是 DA 结果发布时点 = label 可见时点）。已确认不影响任何现有 X 特征。
- **Model Committee 降级**：不再是线上架构，退化为分析工具。
- **诚实结论**：V0.2 相对 V0.1 **没有提高 PnL**（本窗口 Model+Gate −820 vs V0.1 Committee+Gate +962）。架构价值在于**风险可拦截 / 可解释 / 可审计 / 防穿越**，不吹 PnL。

## 2. 组件依赖与数据流（V0.2）

```
canonical.parquet（KEEP：无泄漏特征层）
   ↓ 只消费 X 区 38 特征（全部 <= 10:00 cutoff）
① Production Predictive Model（MODIFY：单一模型，只输出预测量）
   ↓ expected_return / prob_positive / prob_negative / confidence / uncertainty
② Agent Evidence Collection（ADD：当前全 UNCERTAIN，无真实数据源）
   ↓
③ Evidence Time Gate（ADD：published_at <= decision_cutoff 才放行，否则进 ⑧）
   ↓ decision_eligible=True 的 Pre-decision Evidence
④ Case / Knowledge Retrieval（ADD：18 案例，只检索不决策）
   ↓
⑤ Risk Gate（ADD 独立模块：R7a/R7b/R6 REJECT、R4 WARNING + reason_code）
   ↓ PASS / PASS_WITH_WARNING
⑥ White-box Rule Engine（ADD 独立模块：BUY_DA / SELL_DA / NO_TRADE 三态）
   ↓
⑦ Human Confirmation（ADD：交易员拍板，human_review_status）
   ↓
⑧ Post-trade Review（ADD：真实 RTPD 结算；UNFORESEEABLE_EVENT 归因）
```

**关键约束变化**：V0.1 的防泄漏只约束"特征层"（X 的 available_at）；V0.2 把同一铁律延伸到"证据层"——任何外部证据必须由程序（Time Gate）判定 `published_at <= decision_cutoff` 才能进 ⑤⑥，杜绝"LLM 拿未来新闻解释交易"的穿越。

## 3. 对四个目标维度的真实影响（对照 `docs/v0.2_backtest.md`）

| 目标 | V0.1 实际 | V0.2 实际 | 真实变化 |
|---|---|---|---|
| **减少尾部亏损** | Committee 无 gate：maxDD −147,957 / worst −2,216 / CVaR1 −1,056；+gate 后 −654 / −113 / −74 | Model only：maxDD −138,374 / worst −2,216 / CVaR1 −1,096；+gate 后 −3,046 / −208 / −198 | **Gate 对尾部是数量级压制**，但 V0.1 gate 已经做到，非 V0.2 独有。V0.2 残余尾部来自 CONTROLX SELL（v2 模型额外产生的、gate 按设计不拦的 DA 崩塌交易），比 V0.1 committee+gate（−654）更深——**V0.2 在"尾部绝对值"上不优于 V0.1 gate 后** |
| **减少无意义交易** | Committee 1,523 笔 / 48.8%（几乎全是亏钱 CONTROLX BUY） | Model+Gate 181 笔 / 5.8%（CONTROLX SELL + SNLNDRO SELL）；Full Pipeline 同 | **交易覆盖显著下降**，Remove Committee + 单模型 + gate 的共同效果；保留的交易是"唯一安全节点 SELL + 未拦截的 CONTROLX SELL" |
| **解释** | 黑盒概率 + 事后归因 | Decision Card / evidence / gate reason 全程白盒；Rule Engine 逐笔 reason_code | **真实变化（V0.2 主要价值之一）**：每笔决策从输入到建议的完整链路可读 |
| **可审计** | 预测 CSV + 指标表 | 8 步流水线 + Post-trade Review（UNFORESEEABLE_EVENT）+ Case Library + Time Gate 审计字段 | **真实变化（V0.2 主要价值之二）**：决策轨迹可回放、时间门槛可验证、复盘有归因通道 |

**诚实结论（不吹）**：
1. V0.2 **没有提高 PnL**：Model+Gate 本窗口 −820，V0.1 Committee+Gate +962；两者都跑不赢静态全 SELL（+132,746）。
2. V0.2 的"减少尾部亏损"主要通过**保留的 Risk Gate**实现，与 V0.1 同一套规则；架构重组的直接收益是**解释与可审计**，不是收益。
3. V0.2 把"三层委员会"降级是对的：委员会在 V0.1 中 77.7% 的交易是 CONTROLX 双 ML BUY 的重复错误，删除它消除了"错误二次确认"这一结构缺陷。
4. **根本瓶颈未变**：最大亏损机制（CONTROLX RTPD 深度负电价 / DA 崩塌）需要外部供给侧数据（可再生出力/负荷修正/outage）才能事前识别；V0.2 的证据层（②③）已为此预留接口，但**无真实数据源，当前全 UNCERTAIN**——"先解决数据，再谈 Agent"的 stage3 结论仍然成立。
