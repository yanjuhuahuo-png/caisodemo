## 2. 8 个问题回答（Lead）

**Q1：单笔 Web Decision 是否永远展示 DecisionSnapshot.context.market_rule_version？**
**YES。** S1 渲染从 `state.decision.context` 读取（`c.market_rule_version`），非全局 meta。F14/P1/P4 守护。

**Q2：Time Gate 是否只使用 available_at，不再 fallback published_at？**
**YES。** `Evidence.time_eligible` / `decision_service` / Web 审计 / `audit.py` 全部 available-at-only。P5 源码 + 行为断言。

**Q3：available_at 缺失时，Evidence 是否默认不能进入交易决策？**
**YES。** `time_eligible=False` + `MISSING_AVAILABLE_AT`（P6）；published 即真正可用时刻由 Schema 入口显式迁移 `available_at=published_at`（诚实标注），GFS 12Z/18Z 无可靠 vintage 显式标注缺失。

**Q4：Golden Case E 是否使用真实历史 Evidence Snapshot，而不是 MOCK 或现场联网依赖？**
**YES。** `evidence_demo.json` 为真实历史 GFS 18Z 快照（Open-Meteo 历史档案），`HistoricalSnapshotEvidenceAdapter` 在 DEMO MODE 加载（本地、不联网）；`contains_mock=false`（P10/P11）。

**Q5：Golden Case E 是否稳定展示 available_at > cutoff → NOT ELIGIBLE？**
**YES。** 快照 `available_at=2026-07-09T00:00:00 > cutoff 2026-07-08T17:00:00` → rejected + `AVAILABLE_AFTER_CUTOFF`，页面 S4 明确展示 Forecast Run / Published At / Available At / Decision Cutoff / Decision Eligible: NO / Reason（P12）。

**Q6：这个被拒绝 Evidence 是否完全不改变最终交易结果？**
**YES。** P13：加入 Post-cutoff 证据前后 `final_recommendation` / `risk_gate` / `expected_return` 完全一致（被拒证据不进入 Risk Gate / Rule Engine / Model / Final）。

**Q7：当前 Demo 页面是否能明确区分 DATA MODE 与 EVIDENCE MODE？**
**YES。** 顶部状态栏 `DATA MODE: FULL/DEMO` + `EVIDENCE MODE: HISTORICAL_SNAPSHOT/LIVE/NONE`；S1 亦显示单笔 evidence_mode 与来源（P16/P17）。

**Q8：本轮是否修改任何交易核心 / Alpha / Risk Rule / PnL？**
**NO。** 模型、Alpha、Risk Gate、Rule Engine、BUY/SELL/NO_TRADE、PnL、Golden Case outcome 全部冻结。5 个 Golden Case final/gate 与 V0.3.1.2 完全一致（P14/F11）。本轮全部为展示一致性 / Time Gate 语义 / 证据稳定性 / 审计 / 措辞加固。

## 4. 诚实边界

- DEMO 证据快照在本完整数据机用真实 GFS 18Z 历史数据生成（`build_evidence_demo.py`，含 summary/raw_source_id/时间字段）；真正 clean clone 上 `evidence_demo.json` 随 `demo_artifacts/` 一起 checkout，`HistoricalSnapshotEvidenceAdapter` 本地加载，不依赖网络。
- 页面"2026-04-30 → PRE"无法在 Web 直接展示（Web 支持决策日 2026-06-01~08-04，target 全在 2026-05-01 后）；PRE 边界在 service 层 `run_decision` 验证（target 2026-04-30 → PRE），Web 支持窗口内全部 POST，且展示值恒等于 snapshot context。
- FULL vs DEMO 一致性（H4/D4/P14）在本完整数据机实跑 5/5；clean clone 上该测试按设计 SKIP（需完整数据机复核）。
- available-at-only 后，FULL LIVE 模式若 18Z 演示证据无可靠 vintage → rejected `MISSING_AVAILABLE_AT`，Audit Evidence Availability 会如实显示 WARNING（诚实标注，非隐藏）；Case E 的 DEMO 快照显式写 available_at → 稳定 AVAILABLE_AFTER_CUTOFF。
