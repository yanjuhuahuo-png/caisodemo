## 4. 两个核心问题的最终回答

### 问题一：Predictive Model 是否存在稳定 Alpha？

**答案：WEAK（真实但极弱，不足以形成稳定 alpha）**

数据证据：
- 方向准确率 60%+、AUC 0.57–0.65（**存在可学的微弱信号**）。
- 但 **98% 亏损来自 BUY**（CONTROLX BUY test −117,644，赔率倒挂 1:4.5）；根因 = **expected_return 是中位数预测（quantile 0.5），PnL 按均值结算**——CONTROLX test mean +84 / median −33.7，模型看中位数出 BUY，右尾把均值抬正 → EV 恒负。
- **Regime shift 未被识别**：6/17 起 regime 转强（roll_mean_30d +145~+196），模型仍 100% BUY；spearman(er, actual)=−0.059（反向无信息）。
- **所有 regime 均无 alpha**：本 test 窗口模型无任何 BUY/SELL 组合跑赢静态 SELL 漂移基准（+132,746）。

→ **WEAK**：有微弱方向信号，但当前模型目标（中位数）与结算（均值）错位，无稳定盈利 alpha。

### 问题二：Agent Evidence 是否创造真实增量价值？

**答案：INCONCLUSIVE（初步正信号但未证实）**

- A/B 数据：B 组 +1,113 vs A −820，净 +1,933、避免尾损 5,162——**初步正**。
- 但诚实限定（Agent E）：
  1. 用**离线持久性代理**（天气特征 z-score）近似，非在线真实 GFS；
  2. **误伤严重**（单笔最赚 +2,251 被误伤；证据 REJECT 很钝）；
  3. **改进脆弱**：集中 7 月高温日、阈值极敏感（z≥1.5/2.0/2.5/3.0 → +820/+1,933/+773/0）、**val 无法校准 R12**；
  4. **覆盖盲区**：06-23/06-30 DA 崩塌日天气 z 分位低，证据抓不到。
- 需要**接入在线真实 GFS + val 校准**后才能下最终判定。

→ **INCONCLUSIVE**：真实 as-of evidence 机制已建立并首次 A/B，净效果初步为正但未经 val 校准、依赖代理，不能据此宣称"Evidence 有价值"。
