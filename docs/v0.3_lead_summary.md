## 3. Lead 回答 5 个问题

**Q1：MVP 能否完整演示"报价截止前→决策→解释→锁定→实际结果→PnL→复盘"？**
**YES。** `mvp_demo.py` 用真实历史日期跑通完整闭环（已用 5 个黄金案例验证）。

**Q2：MVP 是否存在任何已知信息穿越？**
**NO。** 三道防线：① 特征仅 canonical X 区 38 个 as-of 特征；② evidence/case 均过 Time Gate（GFS 12Z/18Z 回测 FALSE，18Z 被隔离 POST-DECISION）；③ actual_da/rtpd/return 仅在锁定后显示。

**Q3：MVP 是否使用任何 MOCK 数据参与真实推荐？**
**NO。** MOCK 硬隔离（is_mock→backtest+production 恒 FALSE），Decision Card 出现 MOCK 明确标 `DATA NOT ELIGIBLE / DEMO MOCK`，不参与交易建议。

**Q4：当前系统是否已证明可稳定盈利？**
**NO。** 明确标注 `MODEL SIGNAL IS EXPERIMENTAL / CURRENT ALPHA = WEAK / MVP ≠ 已验证盈利系统`。MVP 的价值是"构建了正确、透明、可审计的决策过程"，不是"证明赚钱"。

**Q5：业务方问"为什么 BUY/SELL/NO_TRADE"能否用真实字段完整解释？**
**YES。** 解释来自结构化拼装（Model Output + Feature Stats + Evidence + Similar Cases + Risk Gate Reasons + Rule Engine Reasons），非 LLM 编故事；无法确定用 `UNCERTAIN`。
