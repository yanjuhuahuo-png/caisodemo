**核心观察**：
- **BUY 的 median PnL 是正的（+21~+30）**，mean PnL 却深幅为负（−78~−99）。即「多数 BUY 小赚、少数 BUY 巨亏」——是典型的**损失尾部**（loss tail）分布，不是方向判断全面出错。
- BUY 的 P5/P1 尾部（约 −790/−890）远深于 SELL（约 −113/−350），且 max loss（−2251）约为 SELL（−1175）的两倍。
- Rule 几乎只做 SELL（990 SELL / 6 BUY）——它的期望收益信号（近 14 日均值）在这个正漂移窗口几乎恒为正。

## 2. 是否某一方向结构性风险明显更高？—— 是，BUY

**结论：在本 test 窗口，BUY 是结构性高风险方向；但这主要由节点漂移 + 尾部不对称驱动，不是普适的「BUY 恒坏」。**

证据链：

**① 无条件的 EV 不对称（纯市场环境，不含模型）：**

| node | mean(actual_return) | SELL 平均 | BUY 平均 |
|---|---|---|---|
| CONTROLX_1_N001 | +83.98 | +83.98 | −83.98 |
| ELCAJNGT_7_N001 | −8.25 | −8.25 | +8.25 |
| SNLNDRO_1_N001 | +1.16 | +1.16 | −1.16 |

- CONTROLX 平均价差 +84 $/MWh（正漂移）→ BUY 天然逆漂移，期望为负。
- 注意 ELCA 漂移为负（−8.25）→ **SELL on ELCA 才是逆漂移的那一侧**，后面 node 报告会看到 ELCA 上 SELL 全线亏损。所以「坏方向」随节点漂移符号而变。

**② CONTROLX 尾部不对称（BUY 的亏损侧更长）：**
- CONTROLX spread：skew +0.91（右尾更厚），kurt 3.25，max +2251 vs min −1304。右尾延伸 2 倍于左尾。
- BUY 做错（spread 为正）时的平均亏损 = −448~−460 $/MWh（见下表）；SELL 做错时的平均亏损小得多。
- 单笔最大 BUY 亏损 −2251 出现在 CONTROLX 2026-07-17 H3（稀缺定价事件），一次抹平 30+ 笔典型小赚。

**③ 高命中率 ≠ 盈利（关键反例）：**

| model | CONTROLX BUY | win_rate | 命中时平均 | 做错时平均 | cum |
|---|---|---|---|---|---|
| interpretable | 1476 | 0.661 | +100.75（中位 +63） | **−447.83** | −124,687 |
| catboost | 1213 | 0.617 | +109.23（中位 +62） | **−460.04** | −130,834 |

- 命中率 62~66%，但做错一次平均亏 −450 左右、做对一次只赚 +100，**赔率（payoff ratio）严重倒挂**（约 1 : 4.5）。66% 命中率远不足以覆盖。
- 尾部集中度：merged 交易子集 top-50 事件贡献 −27% 的累计 PnL（top-10 为 −6.7%），即亏损集中在几十笔极端事件；Rule 相反，top-50 贡献 +54%、top-100 贡献 +99.9% 的正 PnL（「彩票式抓右尾」）。

**④ 幅度预测无单调信息：**
- merged 交易子集内 expected_return 与 actual_return：Pearson 0.028 / Spearman 0.172（Rule 子集 Pearson 0.293 / Spearman 0.105）。幅度预测基本无法区分盈亏大小。

## 4. 结论（诚实）

1. **BUY 是本窗口的结构性高风险方向**：原因 = 节点正漂移（CONTROLX mean +84）+ CONTROLX 右尾更长（BUY 的亏损侧）、赔率倒挂（命中时赚 ~100 / 做错时亏 ~450），且 ML 模型在「预测 BUY」上最高置信恰在最危险的稀缺定价日前。**不要默认 BUY/SELL 对称。**
2. **但「BUY 恒坏」不成立**：方向风险随节点漂移符号翻转——ELCA 漂移为负，其 SELL 反而全线亏损（见 node 报告）。正确表述是：**该窗口内 ML 模型（Interpretable/CatBoost）在两个节点上都押了逆漂移方向（CONTROLX 押 BUY、ELCA 押 SELL），两个方向都巨亏。**
3. Rule 的 SELL-only 是唯一正 PnL 方向，但本质是「顺势 + 抓右尾」，不跑赢静态全 SELL 漂移基准（+132,746，见阶段二报告），且 max_loss 仍可达 −1175（CONTROLX 2026-06-30 左尾日）。
4. 任何风控若要降低方向风险，应先按 **节点漂移方向** 对齐（CONTROLX→SELL、ELCA→BUY、SNLNDRO 中性），而非按方向一刀切。
