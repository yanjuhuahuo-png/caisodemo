# 分层分析 5/5 —— Model Agreement（模型一致性）与 Risk Gate（Agent C）

> 数据：三模型预测按 `(node, target_date, hour)` 对齐（4,678 行，无丢失）。
> 分类规则：3/3 同向 = 三模型方向一致且非零；2/3 同向 = 恰两模型方向一致（第三为 0 或相反），按多数方向交易；三者冲突 = 无两模型同向，视为 NO_TRADE（观望）。
> PnL：共识方向为 SELL（>0）→ +actual_return，为 BUY（<0）→ −actual_return。max_drawdown 基于共识交易子集按日汇总。

- **3/3 全一致：方向准确率 76%、正 PnL、max_loss 仅 −339**——非常可靠，但样本极少（150/4,678 = 3.2%），且**全部是 SELL、全部出现在 ELCA(99) 与 SNLNDRO(51)，CONTROLX 一次都没有**。
- **2/3 多数一致：灾难**——2,402 笔、累计 −138,692，几乎就是全部亏损来源。

## 2. 2/3 共识的内部构成（谁跟谁一致，决定了是福是祸）

| combo | 方向 | n | acc | win | cum | mean | max_loss |
|---|---|---|---|---|---|---|---|
| catboost + interpretable | BUY | 2273 | 0.6203 | 0.6203 | **−138,648** | −61.0 | −2216 |
| catboost + rule | SELL | 81 | 0.7531 | 0.7531 | +300.6 | +3.7 | −44 |
| interpretable + rule | SELL | 48 | 0.5208 | 0.5208 | −344.4 | −7.2 | −168 |

- **94.6% 的「2/3 共识」是 CatBoost 与 Interpretable 双双看 BUY**——两个共享特征、结构相似的 ML 模型「互相确认」了一个灾难性信号（CONTROLX 逆漂移 BUY）。这种一致性是**相关误差的放大**，不是独立证据。
- **「Rule + 任一 ML 同向」共 129 笔**：Rule+CatBoost SELL（81 笔）acc 75.3%、max_loss −44，是唯一值得信赖的 2/3 组合；Rule+Interpretable SELL 仅 52.1%。**Rule 的参与是关键**——它是唯一对尾部保持谨慎的模型（几乎只做 SELL，几乎不做 CONTROLX BUY）。

## 3. 一致性 × 节点

| node | 3/3 同向 | 2/3 同向 | 三者冲突 |
|---|---|---|---|
| CONTROLX_1_N001 | **0** | 1184 | 375 |
| ELCAJNGT_7_N001 | 99 | 930 | 531 |

- 全一致在 CONTROLX 上**从不出现**（该节点 ML 模型坚持 BUY、Rule 坚持 SELL，永远对立）；冲突最集中的反而是最平稳的 SNLNDRO（1,220 行）。**「模型越对立」不等于「越危险」——危险在 CONTROLX 的 2/3 伪共识里。**

## 4. 结论：模型一致性能否作为 Risk Gate 的依据？

**部分能，但必须指明「谁一致」，裸的 2/3 多数不能作为 Gate。**

1. **3/3 全一致 = 有效的正向 Gate**：acc 76%、正 EV、尾风险小。但 (a) 覆盖率仅 3.2%，(b) 永不覆盖 CONTROLX（真正需要风控的节点），(c) 它基本复刻 Rule 的 SELL-only 行为，增益有限。
2. **2/3 多数一致 = 无效甚至反向的 Gate**：若按「两模型一致就交易」，会接住 94.6% 的「ML 双看 BUY」→ 累计 −138,692。**两个相关 ML 模型的一致不是独立确认，而是同一错误的二次确认。**
3. **「Rule 在多数方」是更有价值的风向标**：Rule+CatBoost SELL（81 笔，acc 75.3%、max_loss −44）与 Rule 单独 SELL（acc ~62%、+79k）表现都好。若一定要 Gate，建议条件为 **「Rule 必须参与共识」+「方向=SELL」**，即把 ML 当作 Rule 的确认器而非主决策者。
4. **冲突（三者对立）→ 观望**：2,126 行（45%），观望是正确选择（这些行若被强逼交易，落入 ML 的 BUY 主张时即是尾部损失）。

**综合判定**：模型一致性**本身不足以**作为独立 Risk Gate——未经「Rule 参与」条件化的 2/3 共识会系统性放大亏损。可用的 Gate 形态是「3/3 全一致 OR Rule+CatBoost 同向 SELL 才交易，其余观望」，但即便如此，也需接受其不跑赢静态 SELL 漂移基准（+132,746）的事实。
