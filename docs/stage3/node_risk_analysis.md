## 3. CONTROLX 为什么「单次事件打穿策略」？—— 诊断

**答案：节点重尾（右尾更长）+ BUY 逆漂移 + 尾部事件在个别日期集中 + ML 模型在尾部日前最高置信。** 判断不是「数据不足」，也不是「单一 hour 特有」：

1. **节点重尾是根因**：CONTROLX std 343.9、skew +0.91、kurt 3.25。右尾 max +2251 且 >500 的事件在全部 24 个 hour 都出现（每 hour 6~17 笔 / 65 样本），**并非集中在某个特定 hour**——但 **H8–H13 与 H20–H24 更密**（每 hour 12~17 笔 >500），H19 有最深的左尾（−1305）。

2. **尾部事件集中在少数稀缺定价日**：top-12 正收益事件全部在 CONTROLX，且集中在 2026-06-15/06-19/06-20/06-26 与 07-07/07-08/07-09/07-17/07-29 等个位数天数（+1002~+2251）。这些天里模型（Interpretable/CatBoost）恰好大量给 BUY、且 confidence 高（0.56~0.97）。

3. **BUY 特有，不是模型整体失效**：CONTROLX 上 Rule 的 SELL acc 只有 53.9%（方向判断平庸）却 +78,645（顺漂移 + 抓右尾）；Interpretable/CatBoost 的 BUY acc 高达 61.7~66.1%（方向命中率不差）却巨亏。**方向命中率高的同时 PnL 深亏，说明问题在赔率/尾部，不在方向判断本身。**

## 4. 结论（诚实）

1. **CONTROLX = 重右尾节点，是全部策略性风险的源头**。任何策略在该节点的风险预算必须按「右尾可到 +2251、左尾可到 −1305」来设，1 MWh/仓位的名义盈亏可被单笔数千美元打穿。
2. **方向选择在该节点是 ±20 万美元级的分水岭**：BUY 逆 +84 漂移 + 长右尾 = 结构性负 EV；SELL 顺漂移但被 2026-06-30 这类左尾日集中打穿。
3. **ELCA 是第二个风险源**（左尾 −914 + 负漂移），其 SELL 全线亏损；SNLNDRO 是唯一稳健节点。
4. 建议：CONTROLX 只考虑 SELL 且必须对 06-30 式左尾日设硬止损/当日不交易；ELCA 应押 BUY 或直接弃用（cold-start 数据太短）；SNLNDRO 可作为稳健 alpha 载体。
