## 2. 公司 vs 官方对账结论（关键）

- **DA LMP / RTPD(FMM 均值) / `-c` 阻塞分量**：与 OASIS 官方逐小时完全一致（match 1.0 / diff 0.0）→ **可直接用于严格回测**。
- **RTPD 口径确认 = FMM 15min 算术均值**（非 RT5M）；`da_price` = 含 GHG 全口径 LMP。
- **系统负荷预报**：同序列、不同 vintage（公司 2DA 早于 OASIS 最终 DAM 预报）→ 口径差异非错误，但 2DA 逐日 vintage 需补证。

## 3. 5 个核心问题（最终回答）

**Q1：公司当前数据够不够做可信 Baseline Model？**
**答案：PARTIAL。**
价格（label/lag）与官方完全一致（可信）；但 **2DA load forecast 无 vintage、天气是 ERA5 非当时预报** → baseline 可建，但严格 as-of 语义有瑕疵（天气特征只能用历史滞后）。

**Q2：公司当前数据够不够做完整 Agent Historical Backtest？**
**答案：NO。**
缺：① 真实 D+1 天气 forecast 历史档案（vintage）；② 2DA load forecast 发布时间逐日补证；③ Renewable/Outage/Market Notice 缺失。RTPD 口径已通过对账确认为 FMM（可用）。

**Q3：当前最大的三个数据缺口（P0）？**
1. **D+1 天气 forecast 历史档案（vintage）**——公司天气是 ERA5，无法证明决策时可见；需 NCEI GFS 档案或 IFS hindcast 代理。
2. **2DA Load Forecast 发布时间/vintage 补证**——当前 `HISTORICAL_BACKTEST_SAFE=UNKNOWN`，BPM 证据未逐日证实。
3. **Renewable Forecast / Outage 缺失**（P0/P1 交界）——直击负电价时段与 evidence 层；RTPD 口径已由对账确认。

**Q4：哪些数据必须我们自己去 CAISO / NOAA 获取？**
- CAISO OASIS：DA LMP(`PRC_LMP`)、RT5M(`PRC_INTVL_LMP`)、RTPD/FMM(`PRC_RTPD_LMP`)、负荷(`SLD_FCST`)、可再生(`SLD_REN_FCST`)、停电(`TRNS_OUTAGE`)、系统消息(`ATL_OSM`)、阻塞(`PRC_CNSTR`)。
- NOAA/NCEI GFS 原始档案（D+1 天气，需 GRIB2 下载解码）；或 Open-Meteo `Single Runs`+`ecmwf_ifs`（接受 hindcast 代理）。

**Q5：若明天开始 Production Shadow Test，每天 10:00 PT 前应自动抓什么？**
- GFS 00Z/06Z run 对 T+1 的预报（温度/风/辐照），`published_at=run init` 早于 cutoff ✅
- CAISO OASIS `SLD_FCST` 负荷预报（当日取）
- （P1 后）`SLD_REN_FCST` 可再生、`TRNS_OUTAGE` 停电
- 说明：DA LMP 是 **T−1 13:00 后** 可得（作参考/对账，非 cutoff 前输入）；所有抓取走 As-of Schema + Time Gate，存 raw + `retrieved_at`。

## 4. 已建数据底座（可追溯/防穿越）

- **防穿越测试**：As-of 32 + 采集 24 = 56 全过；10:00 口径全仓库统一（含 feature_schema 修正）。
