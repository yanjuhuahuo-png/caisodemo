## 0. 边界与证据声明（诚实，必读）

- 这是 **Signal / Strategy Backtest**，**不是真实 Convergence Bidding PnL**（缺 bid/quantity/award/clearing/settlement/fees）。
- **联网不可用、无已落盘 GFS 缓存**（Agent D 的 `gfs_forecast.py` 需访问 Open-Meteo API）。
- 因此 B 组证据 = **Agent D 的 as-of 判定逻辑 + 现有特征近似**：对目标日 T，取决策时点前（[T-8, T-2]）zone 天气日均值相对历史同月（train+val 窗口）的 z-score；任一变量 |z|≥2.0 → 极端状态 → 证据 severity≥WARNING。这是**持久性预报代理**，严格 as-of（只用决策前可见数据），时间字段复用 D 的 GFS 口径（published_at=D 12Z，cutoff=D 10:00 PT→UTC），`decision_eligible` 由 time_gate 程序计算，全部为 True。
- `directional_effect=UNCERTAIN`（持久性不判 Return 方向）；极端状态只当**风险因子**，由 Risk Gate 新规则 **R12（EXTREME_STATE_EVIDENCE，REJECT）** 消费。R12 纯增量：无证据时不触发（回归验证 backtest_v2.py 主策略仍 181 笔、−820）。

## 3. 结论（诚实评估）

**判定：YES_WITH_LIMITS**

- ZP26：本窗口 Evidence(B) 使 PnL 从 -820 → 1113（+1933）；避免尾部亏损 5162、误伤盈利 3229，净 +1933。风险指标同步改善（maxDD -3046→-1099，Sharpe -0.667→0.994）。
- 但误伤严重：单笔最赚被误伤 2251（CONTROLX_1_N001 2026-07-17 H3 SELL_DA）——证据 REJECT 很钝，避免亏损的同时牺牲了同一极端日的右尾彩票。
- 判定为 YES_WITH_LIMITS 而非 YES，理由：① 仅 65 天单 regime 窗口；② 改进集中在少数极端日（2026-07-17/07-24），阈值极敏感（见敏感性表）；③ val 无法校准 R12 阈值（val 仅 16 笔 gate-accepted 交易，无极端高温样本）——阈值是 2σ 先验而非 val 校准，与其余 gate 阈值口径不一致；④ 证据是离线持久性代理，非真实 GFS D+1 预报；⑤ 2026-06-23/06-30 的 DA 崩塌天气 z 分位低，证据完全抓不到。
- ELCA：A/B 无差异（Risk Gate R7b+R6 已把 ELCA 全部候选关闭，A 与 B 均为 0 交易），证据无法在 ELCA 上体现任何增量。

### 3.1 为什么谨慎（不能因架构复杂就说有价值）

- 本窗口 PnL 改善**集中在少数极端日**（如 2026-07-17 / 07-24 的 CONTROLX SELL DA 崩塌），由极端高温持久性证据标记；改善幅度对阈值极敏感（z=2.0 vs 2.5 差异巨大），属于**小额样本事件**，统计功效不足。
- **证据 REJECT 很钝**：避免 5,162 亏损的同时误伤 3,229 盈利（其中单笔最赚 +2,251 被误伤，见 1.2 表）——同一极端日既含崩塌亏损也含右尾彩票，整日 REJECT 会一并牺牲。
- **val 无法校准 R12 阈值**：val 窗口 gate-accepted 交易仅 16 笔（全是冬季 SNLNDRO SELL），无极端高温样本 → 阈值只能靠 2σ 先验 + test 敏感性展示，**不是 val 校准**（与其余 gate 阈值口径不一致）。
- 2026-06-23 / 06-30 的 CONTROLX DA 崩塌（stage3 已证明事前不可可靠识别）**天气 z 分位低（+0.98 / +0.73），证据完全抓不到** —— 证据只覆盖「持久性极端天气」这一类风险，不覆盖可再生出力/负荷修正/outage 等其它尾部来源。
- 若未来接入真实 GFS D+1 预报（在线），B 组应重跑：真实预报与持久性代理的增量可能不同。
