## 3. Lead 10 问回答

**Q1：第一次看到页面的业务人员，能否 10 秒内知道"做什么"？**
**YES。** 第一屏 = 参数栏 + Hero Card（建议 + 预计价差 + 风控），无 disclaimer 抢占。

**Q2：能否 30 秒内知道"为什么"？**
**YES。** Hero 下三卡"为什么"（模型怎么看 / 风控让不让做 / 最终规则）。

**Q3：主页面是否以中文业务语言为主？**
**YES。** 中文优先，专业术语保留并加中文备注（"预计价差"而非满屏 expected_return）。

**Q4：Agent 是否真正 Streaming 输出？**
**YES。** `/api/ask/stream` SSE，answer_delta 分块逐步显示（U4/U5）。

**Q5：用户能否看到真实 Question → Tool → Result → Answer 工作轨迹？**
**YES。** tool_start/tool_result 来自**真实 Tool 执行**（U6：与确定性 plan 一致），无伪造步骤。

**Q6：页面是否没有展示 LLM private chain-of-thought？**
**YES。** ask_stream 事件无 thinking/CoT 字段；页面仅声明"不展示模型私有思考过程"（U7）。

**Q7：Agent 是否不再默认输出巨大 JSON / 十几位小数 / 内部字段？**
**YES。** 默认业务化（中文 + 2 位小数），技术 JSON 折叠在 details 内（U3/U8）。

**Q8：Case E 是否能让普通业务人员看懂"这条信息来晚了，所以没用"？**
**YES。** S6 明确"报价截止 10:00 PT vs 初始化 11:00 PT + 无法证明 + 它在报价截止以后才开始产生"（U17）。

**Q9：Lock → Reveal → Review 是否形成完整故事？**
**YES。** S7 锁定 → S8 揭晓（亏损 -59.06）+ 发生了什么/为什么/有没有偷看/教训（U19）。

**Q10：本轮是否修改任何交易核心？**
**NO。** Model / DecisionService / Risk Gate / Rule Engine / Evidence Time Gate / Case / PnL / Lock / Reveal 全部未动；U20 验证 5 个 Golden Case expected_return / final 与重构前完全一致。

- S4/S5 Agent 截图为无 LLM Key 的降级态（显示"LLM NOT CONFIGURED" + 真实工具轨迹）；配 Key 后为 LLM 流式回答。
